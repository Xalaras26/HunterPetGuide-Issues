# Hunter Pet Guide - bug reports and ideas

This is where you can report problems with **Hunter Pet Guide**, the hunter pet addon for WoW Forever, or suggest new ideas.

Get the addon on CurseForge: https://www.curseforge.com/wow/addons/hunter-pet-guide

## Report a bug or share an idea

1. Open the **Issues** tab above.
2. Click **New issue**.
3. Pick **Bug report** or **Idea**, and fill in the form.

Screenshots help a lot - you can drag them straight into the form.

## Before you report a bug

- Check that you have the newest version (shown in the guide's bottom-left corner, for example `v2.18.5`).
- Type `/reload` in game and see if it still happens.
- Have a quick look at the open issues - maybe someone already reported it. If so, add a comment there.

Thank you for helping make the guide better!
