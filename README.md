# Xalaras's WoW Forever addons - bug reports and ideas

This is where you can report problems with my WoW Forever addons, or suggest new ideas:

- **Hunter Pet Guide** - hunter pet guide: https://www.curseforge.com/wow/addons/hunter-pet-guide
- **Unlock & Loot** - one click per lockbox for rogues

## Report a bug or share an idea

1. Open the **Issues** tab above.
2. Click **New issue**.
3. Pick **Bug report** or **Idea**, choose your addon, then fill in the form.

Screenshots help a lot - you can drag them straight into the form.

## Before you report a bug

- Check that you have the newest version (shown in the AddOn List).
- Type `/reload` in game and see if it still happens.
- Have a quick look at the open issues - maybe someone already reported it. If so, add a comment there.

Thank you for helping make the addons better!
